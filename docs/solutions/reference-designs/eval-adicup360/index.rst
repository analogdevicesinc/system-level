EVAL ADICUP360
=====================================================================================

.. figure:: images/adicup360_hardware.jpg
   :width: 400
   :align: right

   EVAL-ADICUP360 base board

Overview
-------------------------------------------------------------------------------

The :adi:`EVAL-ADICUP360` is an Arduino-like platform based on the
:adi:`ADuCM360` fully integrated, 3.9 kSPS, 24-bit data acquisition system that
incorporates dual high performance, multichannel sigma-delta (Σ-Δ)
analog-to-digital converters (ADCs), a 32-bit ARM Cortex-M3 processor, and
Flash/EE memory on a single chip. The platform has an Arduino-Due compatible
form factor plus two additional PMOD connectors, an on-board debugger, and an
Eclipse-based development environment (CrossCore Embedded Studio). It is
supported by a set of Analog Devices shields and PMOD modules, and can also be
used with third-party Arduino shields.

Features:

- ADuCM360 with dual 24-bit Σ-Δ ADCs, ARM Cortex-M3 core, and Flash/EE memory
- Arduino-Due compatible form factor with two additional PMOD connectors
- On-board debugger/programmer accessed over the DEBUG USB port
- USER USB virtual serial (UART) port for terminal communication
- Free, Eclipse-based CrossCore Embedded Studio tool chain (IAR and Keil also supported)

Applications:

- Precision analog measurement and data acquisition
- Sensor interfacing (temperature, gas, pH, accelerometer, thermocouple, soil, light)
- Rapid prototyping and evaluation with Analog Devices and third-party shields
