ADRV936x RF SOM Certifications
==============================

Information regarding environmental and mechanical testing is listed here.
Sinusoidal vibration, random vibration, shock testing etc. The ADRVx RF SOM
family is tested against various military (https://mil-std.org) and Information
Technology Standards (NIST) using external vendors with the appropriate
equipment. All details and results of such are maintained in the test reports
below.

ADRV9364-Z7020
--------------

- :dokuwiki:`SOM1 Emissions and Immunity CE Mark Test Report <_media/resources/eval/user-guides/adrv936x_rfsom/analog_devices_picozed_sdr1_emc_emissions_and_immunity_ce_mark_test_report_rev_1_0.pdf>`

  - This report contains tests results for:

    - EN 55022:2010 unwanted emissions
    - EN 55024:2010 immunity

- :dokuwiki:`SOM1 Environmental Test Report <_media/resources/eval/user-guides/adrv936x_rfsom/1604-049na_analog_devices_inc_report.pdf>`

  - This report contains the results for:

    - MIL-STD-202G testing
    - MIL-STD-810G testing

- `UL 94V0 flammability rating <https://www.shopulstandards.com/ProductDetail.aspx?productid=UL94>`__

  - :dokuwiki:`UL On line Certification <_media/resources/eval/user-guides/adrv936x_rfsom/e229342_sunshine_zpmv2.pdf>`
