Introduction
------------

The EVAL-ADE1202EBZ reference design board allows the performance of the
:adi:`ADE1202` Binary Input IC to be evaluated in a context very similar to a
real binary input interface application. The kit requires purchasing a second
board: the controller board for the system demonstration platform
(:adi:`EVAL-SDP-CB1Z <SDP-B>`). The ADE1202 evaluation kit includes evaluation
software, written in LabVIEW®, which provides access to the registers and
features of the device using a PC interface. The EVAL-SDP-B is required to use
LabVIEW. Also available are software drivers written in C which can be
compiled and loaded to the :adi:`EVAL-SDP-CK1Z <SDP-K1>` evaluation board
through the MBED online development environment.

Refer to
:adi:`UG-1679 <media/en/technical-documentation/user-guides/eval-ade1202ebz-ug-1679.pdf>`
for further instructions on setting up and using the evaluation hardware.
