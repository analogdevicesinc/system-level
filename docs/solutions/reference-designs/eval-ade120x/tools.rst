Tools and Driver Details
========================

This chapter provides all the necessary steps to download, install, and setup
the software environment from Analog Devices.

It contains two main sections:

- :doc:`tools/labview_setup_guide`: provides all the necessary instructions on
  how to download and install the LabVIEW GUI.
- :doc:`tools/software_drivers`: provides information about using the provided
  software drivers to control the ADE120x devices using a microcontroller and
  embedded code.
