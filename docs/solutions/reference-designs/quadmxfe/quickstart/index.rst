Quick start guide
===============================================================================

The Quick start guides provide simple step by step instructions on how to do
an initial system setup for the
:adi:`ADQUADMXFE1EBZ <en/design-center/evaluation-hardware-and-software/evaluation-boards-kits/Quad-MxFE.html>`
board on the :xilinx:`VCU118` FPGA development board. In this guide, we will
discuss how to program the bitstream and boot a Linux distribution.

Supported carriers
-------------------------------------------------------------------------------

The :adi:`ADQUADMXFE1EBZ <en/design-center/evaluation-hardware-and-software/evaluation-boards-kits/Quad-MxFE.html>`
connects to the carrier via an FMC+ extender.

   :header-rows: 1

   - - FPGA board
     - Connector
   - - :xilinx:`VCU118`
     - FMC+
