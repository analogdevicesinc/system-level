VCU118 Quick start
===============================================================================

This guide provides quick instructions on how to setup the
:adi:`ADQUADMXFE1EBZ <en/design-center/evaluation-hardware-and-software/evaluation-boards-kits/Quad-MxFE.html>`
on:

- :xilinx:`VCU118` FMC+

.. image:: ../../images/vcu118.png
   :width: 900

Using Linux as software
-------------------------------------------------------------------------------

.. _quadmxfe quickstart vcu118 necessary-files:

Necessary files
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. note::

   This carrier only has programming logic (PL) and, thus, a MicroBlaze soft
   core is necessary to run Linux. As such, the files required for running
   Linux need to be manually built.

The following files are needed for the system to boot:

- HDL bitstream file: ``system_top.bit``
- Linux Kernel image: ``simpleImage.strip``

Instructions on how to manually build the boot files from source can be found
here:

  - :ref:`linux-kernel microblaze`
  - :external+hdl:ref:`ad_quadmxfe1_ebz` build documentation. More HDL build
    details at :external+hdl:ref:`build_hdl`

.. important::

   Multiple JESD204 configurations are available for this platform. Make sure
   you select the devicetree and bitstream that match your specific use case
   and hardware revision. See the README in the
   :git-hdl:`ad_quadmxfe1_ebz VCU118 HDL project <projects/ad_quadmxfe1_ebz/vcu118>`
   for the full list of supported configurations.

Required software
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- :xilinx:`Xilinx Vivado/Vitis <support/download.html>` (includes XSCT)
- A UART terminal (Putty/Tera Term/Minicom, etc.) with baud rate 115200 (8N1)

Required hardware
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- :xilinx:`VCU118` FPGA board and its power supply
- :adi:`ADQUADMXFE1EBZ <en/design-center/evaluation-hardware-and-software/evaluation-boards-kits/Quad-MxFE.html>`
  Quad-MxFE evaluation board and its 12V power supply
- FMC+ extender
- 500 MHz reference oscillator (~0 dBm)
- 2x Micro-USB cables (UART + JTAG)
- Ethernet cable
- SMA cables (as needed for loopback testing)
- Fan/heat sinks installed on the Quad-MxFE board

More details can be found at :ref:`Prerequisites <quadmxfe prerequisites>`.

Testing
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Creating the setup
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

.. image:: ../images/quad_mxfe.png
   :align: center
   :width: 600

.. esd-warning::

Follow the steps in this order, to avoid damaging the components:

#. Install fan/heat sinks on the Quad-MxFE board if not already done
   (see :ref:`Fan Installation <quadmxfe boardhardwaredetails>`)
#. Connect the ADQUADMXFE1EBZ to the :xilinx:`VCU118` via the FMC+ extender
#. Connect the 500 MHz reference oscillator to J41 on the Quad-MxFE board
#. Plug-in an Ethernet cable from your router/switch (or USB-to-Ethernet dongle)
   to the :xilinx:`VCU118` Ethernet port
#. Connect USB UART (Micro-USB) to your host PC
#. Connect USB JTAG (Micro-USB) to your host PC
#. Open a serial terminal (PuTTY, etc.) configured for 115200-8N1 on the
   second USB COM port (the first one is the system controller)
#. Power on the 500 MHz oscillator
#. Power on the Quad-MxFE board (12V supply)
#. Power on the :xilinx:`VCU118` board
#. Program the board using ``xsdb`` or ``xsct``. See generic instructions for
   programming MicroBlaze-based systems at :ref:`linux-kernel microblaze`.
#. Observe console output messages on your terminal

:ref:`XSDB <linux-kernel microblaze boot>`, the Linux kernel begins booting and

to PC, it typically registers two USB COMx/ttyUSBx ports. The first one is
connected to the system controller, while the second one is connected to the
FPGA and features the serial terminal. Make sure a UART terminal is open at
115200-8N1 on the second port before issuing ``con``.

Useful commands for the serial terminal
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

The below commands are to be run in the serial terminal connected to the FPGA.

To find out the IP of the FPGA board, run the following command and take the
IP specified at "eth0 inet":

.. shell::

   $ifconfig

When the system starts it tries to acquire an IP using the DHCP protocol. In
case it fails DHCP it will configure a static IP address of ``192.168.2.1``.

To see the IIO devices detected, run:

.. shell::

   $iio_info | grep iio:device

.. note::

   See :ref:`Cmd Line <libiio cli>` for more IIO command-line utilities.
   All IIO commands can be used locally or remotely. When using the remote
   backend, install libiio for your platform from
   :git-libiio:`Latest Libiio release <releases+>`.

To connect via SSH from a remote PC:

.. shell::

   $ssh root@<board-ip>

Check JESD204 link status
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

.. image:: ../images/image2019-12-4_10-32-57.png
   :align: center
   :width: 800

.. important::

   Both Links must be in ``DATA``

To check the link status from the serial terminal:

.. shell::

   $jesd_status -s

To check the link status from SSH:

.. shell::

   $ssh root@<board-ip>
   $jesd_status

To power off the system, run:

.. shell::

   $poweroff

To disconnect XSDB when done:

.. shell::
   :show-user:

   xsdb% disconnect
