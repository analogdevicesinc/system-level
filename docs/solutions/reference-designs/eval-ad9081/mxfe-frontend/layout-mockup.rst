Size estimate
===============================================================================

The example layout below provides an effective size estimate for the RF front
end. The total PCB measures 5 x 2 in (127 x 50.8 mm). Information regarding
the size requirements of the different channels or circuits is highlighted
below:

#. Rx ch = 4.00 sq. in
#. Tx ch = 3.53 sq. in
#. Digitizer + clk = 4.00 sq. in
#. RF PSN = 0.88 sq. in
#. Digitizer PSN = 2.56 sq. in
#. Fixed LO = 1.13 sq. in
#. Tunable LO = 3.90 sq. in
