Startup Guide
===============================================================================

This guide will help you get started with the EVAL-ADTF3175-NXZ evaluation kit.

Kit Contents
-------------------------------------------------------------------------------

The package includes:

- ADTF3175-NXZ Evaluation Module

  - ADTF3175 Imager Module
  - i.MX8 M Plus SOM (SolidRun)
  - Camera Interface Board

- 16GB flashed microSD card (pre-installed)
- USB-C to USB-C cable (Supports PD 2.0, and USB 3.1)
- Tripod

.. figure:: images/adtf_eval_whatsinthebox.jpg
   :alt: EVAL-ADTF3175-NXZ Kit Contents
   :align: center
   :width: 500

   EVAL-ADTF3175-NXZ Kit Contents

Software Download
-------------------------------------------------------------------------------

Before starting, download and install the software package. See the
:doc:`Software Installation Guide <software_installation>` for detailed
instructions.

Startup Instructions
-------------------------------------------------------------------------------

Follow these steps to get the camera up and running:

1. Unpack the camera equipment from the box
2. Mount camera on the tripod. Orientation shown in image below

.. figure:: images/img_01812.jpg
   :alt: Camera mounting
   :align: center
   :width: 400

   Camera Mounting Orientation

3. Connect USB-C cable to the module
4. Connect the other end to your laptop via USB-C

.. figure:: images/img_0186.jpg
   :alt: USB-C connection
   :align: center
   :width: 400

   USB-C Connection to Laptop

5. Wait for the green light indicator under the USB-C connector on the module
   to light up

.. figure:: images/capture33.png
   :alt: Green light indicator
   :align: center
   :width: 400

   Green Light Indicator (Ready)

6. Run the :doc:`ADIToFGUI <aditofgui>` application
