Application Example Reference Designs
=====================================

This chapter contains various reference designs available for the base board and
the various add on modules. Each sub-section describes the demo program, how to
setup the hardware, how to obtain the source code, and finally, how to import
the project in the Eclipse workspace and to run it.

The following projects are currently available:

-  :ref:`Blinking LEDs Demo <eval-adicup3029 reference_designs demo_blink>` - Shows the basic steps of creating a new project for the :ref:`EVAL-ADICUP3029 base board <eval-adicup3029 hardware adicup3029>`, running and debugging the software.
-  :ref:`Command Line Interpreter Demo <eval-adicup3029 reference_designs demo_cli>` - A Command Line Interpreter (CLI) demo project for the :ref:`EVAL-ADICUP3029 base board <eval-adicup3029 hardware adicup3029>`.
-  :ref:`Accelerometer Demo using Wi-Fi <eval-adicup3029 reference_designs demo_adxl362>` - Illustrates the functionality of the ADXL362 3-axes accelerometer. It works with the :ref:`EVAL-ADXL362-ARDZ Shield <eval-adicup360 hardware adxl362>`.
-  :ref:`Impact Measurement Demo using Bluetooth <eval-adicup3029 reference_designs demo_adxl372>` - Illustrates the functionality of the ADXL372 3-axis high-g accelerometer. It works with the :ref:`EVAL-ADXL372-ARDZ Shield <eval-adicup3029 hardware adxl372>`.
-  :ref:`PMOD Accelerometer Demo <eval-adicup3029 reference_designs demo_pmodacl2>` - Illustrates the functionality of the ADXL362 3-axes accelerometer. It works with the `PmodACL2 from Digilent <http://store.digilentinc.com/pmod-acl2-3-axis-mems-accelerometer/>`_.
-  :ref:`Temperature Demo <eval-adicup3029 reference_designs demo_adt7420>` - Ambient temperature measurement example using the 16-bit ADT7420 digital temperature sensor. It works with the :ref:`EVAL-ADT7420-PMDZ Shield <eval-adicup360 hardware adt7420>`.
-  :ref:`pH Measurement Demo <eval-adicup3029 reference_designs demo_cn0326>` - pH Measurement System with Temperature Compensation that works with the :ref:`EVAL-CN0326-PMDZ PMOD <eval-adicup360 hardware cn0326>`.
-  :ref:`Toxic Gas(CO) Detection Demo using Bluetooth <eval-adicup3029 reference_designs demo_cn0357>` - Measuring toxic gases using electrochemical sensors that work with the :ref:`EVAL-CN0357-ARDZ Shield <eval-adicup360 hardware cn0357>` and sending it to a smart device via Bluetooth.
-  :ref:`Visible Light(RBG)Detection Demo <eval-adicup3029 reference_designs demo_cn0397>` - Measuring visible light intensity and spectrum concentration levels without optical filters or other mechanical components using the :ref:`EVAL-CN0397-ARDZ Shield <eval-adicup360 hardware cn0397>`.
-  :ref:`Soil Moisture and pH Measurement Demo using Wi-Fi <eval-adicup3029 reference_designs demo_cn0398>` - Measures the moisture level and and pH value of different kinds of soil using the :ref:`EVAL-CN0398-ARDZ Shield <eval-adicup360 hardware cn0398>` and sending the data over Wi-Fi.
-  :dokuwiki:`BLE device Documentation <resources/eval/user-guides/eval-adicup3029/reference_designs/ble_packet>` - Documentation referring to ADI BLE message format for use with IOTnode mobile application
-  :ref:`Optical Platform Demo <eval-adicup3029 reference_designs demo_cn0503>` - Can measure different qualities of a liquid, such as colorimetry, fluorescence, turbidity, etc., using the :dokuwiki:`EVAL-CN0503-ARDZ Shield <resources/eval/user-guides/circuits-from-the-lab/cn0503>`.
